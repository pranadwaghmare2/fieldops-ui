# FieldOps UI bare React Native example

This Expo-free consumer sketch mirrors `example-expo` and demonstrates all five
public `fieldops-ui` components. It keeps generated `ios/` and `android/`
projects out of the library repository; use these files as the JavaScript root
of a React Native Community CLI 0.74 app.

## Run

1. Build the library from the repository root with `npm run build`.
2. Install this example with `cd example-bare && npm install`.
3. Supply the native `ios/` and/or `android/` project generated by the React
   Native Community CLI for an app named `FieldOpsBare`.
4. Run `npm start`, then launch that native target from Xcode or Gradle.

The package consumes the parent exactly as an external local package through
`"fieldops-ui": "file:.."`; it does not import from `src/`.

## NativeWind wiring

- `babel.config.js` adds `nativewind/babel` and keeps Reanimated's plugin last.
- `metro.config.js` wraps the community Metro config with `withNativeWind`,
  points it at `global.css`, and watches the parent package behind `file:..`.
- `tailwind.config.js` uses both `nativewind/preset` and
  `fieldops-ui/preset`, and scans the library's compiled `lib/` output.
- `index.js` imports `global.css` before registering the application.

The `.default` access in `tailwind.config.js` is intentional: Bob publishes the
preset as ESM, so CommonJS `require` exposes its default export there.
